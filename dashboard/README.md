# 电商核心数据看板 · GitHub Pages 版

与本地 Streamlit 看板使用同一份已核对数据，保留单页布局、月份/州/品类筛选、六项指标、交互趋势、地区/品类 Top 10、商品搜索与排序、CSV 导出，以及完整报告入口。商品表每页显示 50 行，导出涵盖全部匹配商品。

此版本是 HTML + CSS + JavaScript 静态页面，不运行 Python 服务。图表库 Plotly.js 4.1.1 与压缩数据快照随仓库发布，不依赖第三方 CDN。使用现代浏览器的 DecompressionStream 解压 gzip 快照。

## 数据口径

2017-01 至 2018-08，按购买月份归属，最终 delivered 的订单，商品 price 不含运费，币种 R$。所有筛选在商品明细粒度上计算；客户和订单在当前范围去重，选中品类后不会把整个订单的其他品类金额带入。

价格以整数分加总。期间去重客户数不等于各月客户数相加，跨州客户可能被多个州分别计入。订单均商品金额是选中商品金额除以符合条件的订单数，不是筛选品类后整个订单的金额。

区间变化与前一个等长连续月份区间比较；同比与去年同月比较，环比与上月比较。无完整比较期或分母为零时不展示变化率。下降榜只显示负变化，按下降金额从大到小排序。搜索只影响商品表和商品 CSV，月度导出沿用全局筛选。

2017-01 最早记录为 1 月 5 日，2018-08 最后记录为 8 月 29 日；覆盖完整自然月的情况未确认。上述数据边界已在页面标注。

快照含 109,880 商品明细行、96,211 订单、R$ 13,181,027.13 商品金额。原始客户与订单标识不发布，仅使用整数索引保留正确去重；商品 ID 保留以便查询。来源 SQL、生成时间、行结构及快照校验值见 provenance.json。

## 验证和刷新

浏览器计算已与 Pandas 独立结果核对：两年 5/6 月六项指标、月度趋势、地区/品类交叉筛选、空结果、下降排名。搜索、排序、商品分页、CSV、筛选记忆和 390px 窄屏已用 Edge + Playwright 验证。

本地项目 ecommerce-dashboard 中运行 prepare_data.py 后运行 build_static.py，生成 github-pages/；同步其中 dashboard/ 与项目首页到发布仓库即可。静态版源文件在 static-source/，验证脚本 verify_static.py；本地 Streamlit 版本继续保留。
